# QuickSub

QuickSub é uma aplicação web para gerenciamento de assinaturas de serviços. Com ela, você pode cadastrar clientes, serviços, controlar assinaturas, datas de início e fim, status e valores pagos, tudo de forma simples e centralizada.

## Funcionalidades
- Cadastro e autenticação de usuários
- Cadastro de clientes e serviços
- Gerenciamento de assinaturas (início, fim, status)
- Visualização e controle de planos e valores

## Tecnologias Utilizadas
- Backend: Node.js, Express, MySQL
- Frontend: React

## Como usar
1. Instale as dependências com `npm install` nas pastas do backend e frontend
2. Configure o banco de dados MySQL usando o arquivo `dumpsql.txt`
3. Inicie o backend e o frontend com `npm start`
4. Para acessar como administrador, crie um usuário chamado 'admin' com a senha 'admin@123'.

Ideal para quem deseja organizar e acompanhar todas as suas assinaturas em um só lugar!
